# pdf-to-epub

Native macOS app that converts scanned documents (a PDF or a folder of page images)
into EPUB 3, reproducing the document's formatting as faithfully as possible:
headings, paragraphs, illustrations with captions, and footnotes.
Pipeline in `Packages/ScanCore` (CLI `pagescan`), SwiftUI app in `App/`.

## Product decisions

| Topic | Decision |
|---|---|
| Platform | macOS 26+ only. Cross-platform is not a goal. |
| Stack | Swift 6 (strict concurrency, warnings are errors), SwiftUI, Swift Testing. |
| OCR engine | Apple Vision only. Free, on-device, no network calls, no paid services. |
| Document languages | Ukrainian, English, and Ukrainian with English fragments on the same page. |
| Document types (v1) | Fiction and non-fiction with footnotes, illustrations, multi-level headings, lists. |
| Out of scope (v1) | Tables, multi-column layout, math formulas, verse line preservation, LLM-based correction. |
| Distribution | Personal / open-source build. No App Store, no sandbox requirement. |
| Output | EPUB 3 that passes `epubcheck` with no errors. |
| UI strings | Localizable String Catalog: English base, Ukrainian localization. |

Everything written here is English: code, comments, docs, commits, conversation.
Ask the user before adding a dependency, a network call, or an out-of-scope feature.

## Sample sets

The user's own scans are four sets of about 850 PNG pages: **clean pages**,
not scanned pages (clean text, no skew, no running headers, page number at the
bottom, note references as blue links, notes collected at the end, illustrations
with captions, a cover and a contents page). Design for this first.

They are commercial material and live only in the git-ignored `Samples/` folder
at the repository root, one sub-folder per document (`PAGESCAN_SAMPLES_DIR`
overrides it). Never read from, copy from or write to a path outside the
repository, and keep their pages and text out of tracked files, docs and commit
messages. `scripts/check-no-samples.sh` (run by the commit and push hooks)
fails when a sample-like file is tracked. Tests that need samples use
`SampleSets.directory` (in `AppModelTests`) and skip when it is `nil`. Committed fixtures are
synthetic pages generated by code (or public-domain).

## Process

- **TDD.** Write the failing test, watch it fail for the right reason, write the minimum code, refactor green. A bug fix starts with a test that reproduces it.
- **Before every commit** run `scripts/check.sh`; the `.githooks/pre-commit` hook does it (`git config core.hooksPath .githooks` once per clone). Heuristic changes also run the golden pages (`docs/testing.md`).
- **Done** means: tests first and green; no lint or compiler warnings; public API has DocC comments; the feature page in `docs/features/` is written or updated and linked from `docs/README.md`; for UI changes, the app was launched and the change checked by hand.
- Build the app with `xcodebuild -project App/PDFToEPUB.xcodeproj -scheme PDFToEPUB build`; convert a folder with `swift run --package-path Packages/ScanCore -c release pagescan <folder>`.

## Environment notes

- After an Xcode update, `swift`, `git` and `xcodebuild` refuse to run until the
  user accepts the licence (`sudo xcodebuild -license`); `xcodebuild` also needs
  `sudo xcodebuild -runFirstLaunch`.
- After changing a public signature, an incremental `swift test` build has
  crashed the test process with signal 11; removing `.build/debug` fixed it.
- A Vision request occasionally never returns. `VisionOCREngine` gives each
  request 180 s and three attempts, then fails with `OCRError.timedOut`.
  Run one `pagescan` at a time when measuring.
- `epubcheck`, `swiftlint` and `swiftformat` are installed (Homebrew).
